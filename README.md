# term·start

Терминальная стартовая страница для браузера: чистый HTML/CSS/JS, без зависимостей и сборки. Тёмные темы без неона — фосфор, янтарь и «бумага».

## Запуск

Вариант 1 — просто открыть `index.html` в браузере (двойной клик).

Вариант 2 — как домашняя страница: поднять сервер и указать адрес в настройках браузера:

```sh
python3 -m http.server 8080
# затем в настройках браузера: домашняя страница = http://localhost:8080
```

## Возможности

**Поиск**

- 30 поисковых движков: Google, DuckDuckGo, Brave, Startpage, Mojeek, Marginalia, SearXNG, Яндекс, Википедия (ru/en), YouTube, GitHub, Stack Overflow, MDN, Хабр, Кинопоиск, OSM, Ozon и др.
- `!bang` — разовый поиск: `!yt котики`, `!w Гагарин`
- `!bang` без текста — сменить движок по умолчанию
- `tab` — переключение движка по чипсам
- расширенный поиск (`adv`, `a` или `:advanced`): точная фраза, исключения, OR, сайт, тип файла, `intitle:` / `inurl:`, период и язык/регион для Google и DuckDuckGo
- в DuckDuckGo используются его операторы поиска; период доступен от суток, а выбор языка задаёт регион выдачи
- прямой ввод URL (`example.com`) — переход без поиска
- подсказки из закладок, быстрых ссылок и bang-движков

**Быстрые ссылки**

- сетка ссылок с клавишами `1–9` или своей клавишей на ссылку
- группы (категории) и drag&drop: перетаскивание меняет порядок, бросок на заголовок группы переносит ссылку в неё
- добавление/редактирование (`edit` / `e` / кнопка `✎`) и удаление (`×`)

**Бэкап и перенос**

- экспорт конфигурации из настроек включает все параметры, город погоды, снимок полного окна настроек в SVG, дату экспорта и версии приложения/страницы
- импорт проверяет формат и совместимость major-версий до изменения настроек; поддерживаются и старые JSON-бэкапы
- конфигурацию можно перетащить на страницу; сохранённый город загружается как значение по умолчанию для погоды

**Закладки**

- импорт экспортированного `bookmarks.html` (Chrome/Firefox: менеджер закладок → экспорт в HTML) кнопкой или drag&drop
- поиск по названию и адресу, фильтры «все / избранное / недавно добавленные»
- сворачиваемые папки со счётчиками; старые папки после обновления автоматически сворачиваются
- добавление, переименование и удаление пустых папок; перенос закладок между папками и удаление закладок
- избранное выводится отдельной группой и не дублируется в папках; новые закладки — добавленные в term·start за последние 30 дней

**Быстрые действия**

- палитра команд: `ctrl+k` или `:cmd` — `:theme`, `:engine`, `:add`, `:import`, `:clear-bm`, `:newtab`, `:reset`, `:settings`, `:help`
- в строке поиска тоже работают `:команды`

**Кастомизация**

- 3 темы: phosphor / amber / paper (клавиша `t` или клик по статуслайну)
- шрифт: Iosevka, Victor Mono, JetBrains Mono, Fira Code, Cascadia Code или свой (подключаются с CDN, офлайн — системный фолбэк)
- фон: свой цвет (hex) и/или картинка по URL с настраиваемым затемнением
- стиль рамок панелей: solid / dashed / double
- вкл/выкл блоков ссылок и закладок, подсказок, открытие в новой вкладке
- всё хранится в localStorage; полный сброс — `:reset`

## Горячие клавиши

| Клавиша                     | Действие                                         |
| --------------------------- | ------------------------------------------------ |
| `/`                         | фокус в поиск                                    |
| `1–9`                       | открыть быструю ссылку (или свою клавишу ссылки) |
| `tab`                       | следующий движок                                 |
| `ctrl+k`                    | палитра действий                                 |
| `ctrl+,`                    | настройки                                        |
| `a`                         | расширенный поиск                                |
| `e` / `i` / `t` / `b` / `?` | ссылки / импорт / тема / закладки / помощь       |
| `esc`                       | очистить ввод / закрыть диалог                   |

## Файлы

- `index.html` — разметка
- `style.css` — темы и стили
- `app.js` — вся логика (движки, парсер ввода, localStorage, импорт закладок)
