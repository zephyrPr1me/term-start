# RYU · 龍

Стартовая страница для браузера из трёх отдельных пространств:

- **Tateru** (建てる, «строить») — `index.html`: поиск, быстрые ссылки, закладки, погода.
- **Kowasu** (壊す, «ломать») — `hack.html`: отдельная среда для security research, defensive-практик, учебных лабораторий и локальных заметок.
- **Off-Duty** — `leisure.html`: терминальное пространство для отдыха, быстрых ссылок на развлечения и коротких дыхательных пауз.

## Запуск

Нужен Node.js. Установите зависимости и запустите Vite:

```sh
npm install
npm run dev
```

Vite выведет локальный адрес; обычно это `http://localhost:5173`. Страницы доступны по `/`, `/hack.html` и `/leisure.html`. Чтобы собрать статические файлы в `dist/`, выполните `npm run build`; локально проверить сборку можно через `npm run preview`.

`Ctrl+Enter` циклически переключает страницы: Tateru → Kowasu → Off-Duty → Tateru.

## Tateru — возможности

**Поиск**

- 27 поисковых движков: Google, DuckDuckGo, Brave, Startpage, Mojeek, Marginalia, SearXNG, Яндекс, Википедия (ru/en), YouTube, GitHub, GitLab, Stack Overflow, npm, MDN, Хабр, grep.app и др.
- `!bang` — разовый поиск: `!yt котики`, `!w Гагарин`
- `!bang` без текста — сменить движок по умолчанию
- `tab` — переключение движка по чипсам
- расширенный поиск (`adv`, `a` или `:advanced`): точная фраза, исключения, OR, сайт, тип файла, `intitle:` / `inurl:`, период и язык/регион для Google и DuckDuckGo
- в DuckDuckGo используются его операторы поиска; период доступен от суток, а выбор языка задаёт регион выдачи
- прямой ввод URL (`example.com`) — переход без поиска
- подсказки из закладок, быстрых ссылок и bang-движков

**Быстрые ссылки**

- сетка ссылок с клавишами `1–9` или своей клавишей на ссылку
- стартовый набор ссылок — только инструменты разработки, документация и playgrounds
- при обновлении удаляются только прежние стандартные ссылки на календарь, Кинопоиск, Ozon и Wildberries; остальные пользовательские ссылки сохраняются
- фавиконки сайтов загружаются через Google Favicon; если иконка недоступна, показывается первая буква названия
- группы (категории) и drag&drop: перетаскивание меняет порядок, бросок на заголовок группы переносит ссылку в неё
- добавление/редактирование (`edit` / `e` / кнопка `✎`) и удаление (`×`)

**Бэкап и перенос**

- экспорт конфигурации из настроек включает все параметры, город погоды, снимок полного окна настроек в SVG, дату экспорта и версии приложения/страницы
- импорт проверяет формат и совместимость major-версий до изменения настроек; поддерживаются и старые JSON-бэкапы
- конфигурацию можно перетащить на страницу; сохранённый город загружается как значение по умолчанию для погоды

**Закладки**

- импорт экспортированного `bookmarks.html` (Chrome/Firefox: менеджер закладок → экспорт в HTML) кнопкой или drag&drop
- поиск по названию и адресу, фильтры «все / избранное / недавно добавленные»
- сворачиваемые папки со счётчиками; старые папки после обновления автоматически сворачиваются
- добавление, переименование и удаление пустых папок; перенос закладок между папками и удаление закладок
- избранное выводится отдельной группой и не дублируется в папках; новые закладки — добавленные в RYU за последние 30 дней

**Быстрые действия**

- палитра команд: `ctrl+k` или `:cmd` — `:theme`, `:engine`, `:add`, `:import`, `:clear-bm`, `:newtab`, `:reset`, `:settings`, `:help`
- в строке поиска тоже работают `:команды`

**Кастомизация**

- темы загружаются из `themes.json`; переключение — клавиша `t` или клик по статуслайну
- шрифт: Iosevka, Victor Mono, JetBrains Mono, Fira Code, Cascadia Code или свой (подключаются с CDN, офлайн — системный фолбэк)
- фон: свой цвет (hex) и/или картинка по URL с настраиваемым затемнением
- стиль рамок панелей: solid / dashed / double
- вкл/выкл блоков ссылок и закладок, подсказок, открытие в новой вкладке
- всё хранится в localStorage; полный сброс — `:reset`

### Свои темы

Добавьте объект темы в массив `themes` файла `assets/data/themes.json`. Укажите уникальный `id` из строчных латинских букв, цифр и дефисов, отображаемое `name` и цвета `bg`, `bg-panel`, `bg-inset`, `fg`, `fg-dim`, `fg-mute`, `accent`, `accent2`, `danger`, `border`, `sel`, `status-fg` и `overlay` в формате `#RGB`, `#RGBA`, `#RRGGBB` или `#RRGGBBAA`. Чтобы выбрать тему при первом запуске, задайте её `id` в поле `default`. После изменения обновите страницу.

## Kowasu — возможности

Kowasu использует общую систему тем, но собственную сетку, модули и рабочий контекст — это отдельная исследовательская среда, а не каталог ссылок Tateru.

- те же темы из `themes.json`, переключение клавишей `t` или кликом по статуслайну
- ⚙ открывает левую панель настроек: тема, язык, поисковый движок, плотность и число колонок
- в той же панели можно скрывать и переставлять модули; настройки Kowasu сохраняются отдельно в localStorage
- быстрые ссылки на CISA KEV, NVD, MITRE ATT&CK, Sigma, OWASP и PortSwigger Academy
- модули: контекст угроз, разработка детектов, практические лаборатории, состояние сессии, заметки и личные ресурсы
- NVD/CVE-поиск, заметки текущей сессии и личный набор ссылок; заметки хранятся только в браузере
- публичный IP запрашивается только вручную через api.ipify.org
- движки DuckDuckGo, Google, NVD, CVE.org и GitHub; `tab` в строке поиска переключает движок
- справка `man ryu-kowasu` по клавише `?`; ссылка `建てる tateru` возвращает в режим разработки

## Горячие клавиши

| Клавиша                     | Действие                                         |
| --------------------------- | ------------------------------------------------ |
| `/`                         | фокус в поиск                                    |
| `1–9`                       | открыть быструю ссылку (или свою клавишу ссылки) |
| `tab`                       | следующий движок                                 |
| `ctrl+k`                    | палитра действий                                 |
| `ctrl+,`                    | настройки                                        |
| `a`                         | расширенный поиск                                |
| `e` / `i` / `t` / `b` / `?` | ссылки / импорт / тема / закладки / помощь       |
| `ctrl+enter`                | перейти на следующую страницу                   |
| `esc`                       | очистить ввод / закрыть диалог                   |

В Kowasu работают `/`, `tab`, `t`, `e` (фокус в поле своей ссылки), `?` и `esc`.

## Структура проекта

```text
.
├── index.html                 # Страница Tateru
├── hack.html                  # Страница Kowasu
├── leisure.html               # Отдых и развлечения
├── package.json               # npm-скрипты и Vite
├── vite.config.js              # Многостраничная сборка
└── assets/
    ├── css/
    │   ├── foundation.css     # Переменные, сброс и общие элементы
    │   ├── search.css         # Общий поиск и переключатели движков
    │   ├── links.css          # Общие карточки ссылок
    │   ├── interface.css     # Статусная строка, диалоги и общие элементы управления
    │   ├── tateru.css         # Поиск, быстрые ссылки, закладки Tateru
    │   ├── kowasu.css         # Сетка и модули Kowasu
    │   └── leisure.css        # Терминальная тема страницы отдыха
    ├── data/
    │   └── themes.json        # Палитры тем
    └── js/
        ├── theme-loader.js    # Загрузка и применение тем
        ├── page-switch.js     # Циклическое переключение страниц
        ├── tateru.js          # Поиск, ссылки, закладки и настройки Tateru
        ├── kowasu.js          # Поиск, заметки, ресурсы и настройки Kowasu
        └── leisure.js         # Минутная дыхательная пауза
```

HTML-страницы остаются в корне проекта: существующие адреса Tateru и Kowasu не меняются.

Внутренние идентификаторы (`termstart.v1`, формат бэкапа `term-start/config`, версии `1.0.0`) сохранены намеренно — чтобы не потерять настройки и не сломать импорт старых конфигураций. Ключи Kowasu (`hpTheme`, `hpEngine`, `hpCustomLinks`) тоже сохранены; неизвестные значения темы откатываются к теме `default` из `themes.json`.
